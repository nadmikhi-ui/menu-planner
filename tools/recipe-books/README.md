# Рецепты из книг → `src/data/books.json`

Книги свёрстаны картинками, поэтому текст распознаётся tesseract (rus), затем раскладывается по полям.

1. `python3 ocr3.py <книга.pdf> b|l|d tsv3` — слова с координатами (300 dpi, psm 11), по файлу на страницу.
2. `python3 titles.py tsv3 titles.json` — названия отдельно: вырезка над строкой КБЖУ при 100 dpi читается чище.
3. `python3 build.py tsv3 rec.json` — разделы книг, название, КБЖУ, продукты, шаги из двух колонок, советы; правка ошибок распознавания по словарю книг.
4. Продукты для покупок — парсером приложения (`src/logic/recipe.ts`): скопируйте `products.test.ts.txt` в `src/zz-products.test.ts` и запустите с `REC_IN=rec.json REC_OUT=recp.json npx vitest run`.
5. `python3 assemble.py recp.json ../../src/data/books.json` — разделы приложения, белок, заготовки.

Ручные правки: `fixes.json` — названия по странице (`""` — пропустить), приведение продуктов к одному названию (`""` — убрать), постоянные запасы. `preps.json` — идеи заготовок для морозилки (`match` — по каким продуктам/названиям искать блюда, где заготовка пригодится).
После изменения данных увеличьте `BOOK_LIBRARY_VERSION` в `src/db/books.ts`.
