# Меню недели

PWA для планирования домашнего меню на неделю и списка покупок. Интерфейс на русском, рассчитан на телефон, работает офлайн. Сервера нет: все данные хранятся на устройстве (IndexedDB), перенос между устройствами — через экспорт/импорт JSON.

Требования к функциональности — в [docs/SPEC.md](docs/SPEC.md), правила разработки — в [AGENTS.md](AGENTS.md).

## Требования

- Node.js 20 или новее (проверено на 20.18)
- npm

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173). Чтобы открыть приложение с телефона в той же Wi‑Fi‑сети:

```bash
npm run dev -- --host
```

и зайдите на адрес `Network: http://192.168.…:5173` из вывода.

## Сборка и проверка PWA

```bash
npm run build
```

```bash
npm run preview
```

Сервис-воркер и офлайн-режим работают только в собранной версии (`build` + `preview`, или любая статическая раздача папки `dist/`). Для установки на телефон («Добавить на главный экран») приложение должно открываться по HTTPS — например, после выкладки `dist/` на GitHub Pages, Netlify или Vercel.

## Как опубликовать на GitHub Pages

Сборка и выкладка идут автоматически через GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)): при каждом пуше в ветку `main` запускаются проверка типов и тесты, затем сборка и публикация.

1. Создайте на GitHub пустой репозиторий, например `menu-planner` (без README и `.gitignore`).
2. В папке проекта подключите его и отправьте код (подставьте свой логин):

   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/menu-planner.git
   ```

   ```bash
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь зелёной галочки у запуска «Выкладка на GitHub Pages» (1–2 минуты). Если запуск не начался сам, нажмите **Run workflow**.
5. Приложение откроется по адресу `https://ВАШ_ЛОГИН.github.io/menu-planner/`.

Адрес подпути берётся из названия репозитория автоматически (переменная `BASE_PATH`). Если репозиторий называется `ВАШ_ЛОГИН.github.io` или у вас свой домен, в `deploy.yml` замените значение `BASE_PATH` на `/`. Проверить подпуть локально можно так:

```bash
BASE_PATH=/menu-planner/ npm run build && BASE_PATH=/menu-planner/ npm run preview
```

и открыть `http://localhost:4173/menu-planner/`.

Обновления: после нового `git push` приложение само обновится на телефоне при следующем открытии с интернетом.

## Как установить на телефон

Откройте адрес приложения (он должен начинаться с `https://`) на самом телефоне.

**iPhone (Safari):**

1. Нажмите кнопку «Поделиться» (квадрат со стрелкой) внизу экрана.
2. Прокрутите меню и выберите **«На экран „Домой“»**.
3. Нажмите **«Добавить»**. Иконка «Меню недели» появится на главном экране; запускайте приложение оттуда.

Использовать нужно именно Safari: в других браузерах на iPhone установка может быть недоступна.

**Android (Chrome):**

1. Нажмите меню «⋮» в правом верхнем углу.
2. Выберите **«Установить приложение»** (или «Добавить на главный экран»).
3. Подтвердите. Иконка появится на главном экране и в списке приложений.

После первого открытия приложение работает без интернета.

### Не потеряйте данные

Все данные хранятся только на этом телефоне, сервера нет.

- Установите приложение на главный экран и в **Ещё → Настройки → Хранение данных** нажмите «Защитить данные от удаления». Приложение просит об этом и само при запуске.
- Раз в месяц делайте **Ещё → Экспорт и импорт → Сохранить в файл** и сохраняйте файл в «Файлы» или облако. Приложение напомнит об этом и покажет дату последнего экспорта.
- На новом телефоне: установите приложение, откройте **Экспорт и импорт → Выбрать файл…**.
- Если очистить данные сайта или удалить иконку приложения в Safari, данные исчезнут, поэтому экспорт нужен.

## Что умеет приложение

- **Блюда** — библиотека из семи разделов, автоподсказка раздела по словарю с запоминанием поправок, архив, демо-блюда.
- **Неделя** — автосборка меню по правилам повторов (внутри недели, окно двух недель, чередование белка), ручная правка, предупреждения, утверждение и завершение недели.
- **Пропуски и перенос** — отметка «Пропущено» с причиной, очередь переноса на следующую неделю.
- **Покупки** — список из меню, сгруппированный по местам, с постоянными запасами, отметками и «Поделиться».
- **Морозилка** — идеи заготовок, задачи недели, «Сейчас в морозилке» с подсветкой старых записей.
- **Ещё** — история недель и «Повторить как черновик», настройки, экспорт и импорт JSON.

Подробные требования — в [docs/SPEC.md](docs/SPEC.md), сверка с ними — в [docs/AUDIT.md](docs/AUDIT.md).

## Структура

```
docs/SPEC.md        техзадание
docs/AUDIT.md       ревизия: требование — реализовано / частично / нет
src/types.ts        доменные типы и справочники (разделы, слоты, статусы)
src/db/             Dexie: схема, начальные данные и операции над базой
src/logic/          бизнес-логика (чистые функции) и её тесты
src/components/     общие UI-компоненты (нижнее меню, окна, чипы)
src/screens/        экраны: Неделя, Блюда, Покупки, Морозилка, Ещё (вложенные папки — их окна)
src/storage.ts      запрос постоянного хранилища
.github/workflows/  выкладка на GitHub Pages
```

Тесты лежат рядом с кодом (`*.test.ts`); логика работает без React и браузера, база в тестах — `fake-indexeddb`.

## Хранилище (Dexie, база `menu-planner`)

| Таблица         | Что хранит                                                      |
|-----------------|-----------------------------------------------------------------|
| `dishes`        | библиотека блюд, включая идеи заготовок                         |
| `products`      | справочник продуктов: место покупки, флаг «постоянный запас»    |
| `sortRules`     | пользовательские поправки автосортировки                        |
| `weeks`         | недели меню, их статусы и снимок списка покупок                 |
| `slots`         | приёмы пищи недели (день × завтрак/перекус/обед/ужин) с блюдами |
| `prepTasks`     | задачи «Заморозить на этой неделе»                              |
| `carryOver`     | очередь «Перенос на следующую неделю»                           |
| `freezer`       | «Сейчас в морозилке»                                            |
| `shoppingItems` | отметки «куплено» / «уже есть дома» и ручные позиции списка     |
| `settings`      | настройки и дата последнего экспорта (одна запись `main`)       |
