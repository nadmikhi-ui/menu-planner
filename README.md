# Меню на неделю

PWA для планирования домашнего меню на неделю и списка покупок. Интерфейс на русском, рассчитан на телефон, работает офлайн. Сервера нет: все данные хранятся на устройстве (IndexedDB), перенос между устройствами — через экспорт/импорт JSON.

Требования к функциональности — в [docs/SPEC.md](docs/SPEC.md), правила разработки — в [AGENTS.md](AGENTS.md).

## Требования

- Node.js 20 или новее (проверено на 20.18)
- npm

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173). Чтобы открыть приложение с телефона в той же Wi‑Fi‑сети:

```bash
npm run dev -- --host
```

и зайдите на адрес `Network: http://192.168.…:5173` из вывода.

## Сборка и проверка PWA

```bash
npm run build
```

```bash
npm run preview
```

Сервис-воркер и офлайн-режим работают только в собранной версии (`build` + `preview`, или любая статическая раздача папки `dist/`). Для установки на телефон («Добавить на главный экран») приложение должно открываться по HTTPS — например, после выкладки `dist/` на GitHub Pages, Netlify или Vercel.

## Структура

```
docs/SPEC.md        техзадание
src/types.ts        доменные типы и справочники (разделы, слоты, статусы)
src/db/             схема Dexie (db.ts) и начальные данные (seed.ts)
src/logic/          бизнес-логика (чистые функции) и её тесты
src/components/     общие UI-компоненты (нижнее меню и т.п.)
src/screens/        экраны: Неделя, Блюда, Покупки, Морозилка, Ещё
```

## Хранилище (Dexie, база `menu-planner`)

| Таблица         | Что хранит                                                      |
|-----------------|-----------------------------------------------------------------|
| `dishes`        | библиотека блюд, включая идеи заготовок                         |
| `products`      | справочник продуктов: место покупки, флаг «постоянный запас»    |
| `sortRules`     | пользовательские поправки автосортировки                        |
| `weeks`         | недели меню и их статусы                                        |
| `slots`         | приёмы пищи недели (день × завтрак/перекус/обед/ужин) с блюдами |
| `prepTasks`     | задачи «Заморозить на этой неделе»                              |
| `carryOver`     | очередь «Перенос на следующую неделю»                           |
| `freezer`       | «Сейчас в морозилке»                                            |
| `shoppingItems` | отметки «куплено» / «уже есть дома» и ручные позиции списка     |
| `settings`      | настройки (одна запись `main`)                                  |
