# Техзадание: планировщик домашнего меню на неделю

Веб-приложение (PWA) для планирования домашнего меню на неделю. Интерфейс полностью на русском, mobile-first (основное использование — телефон), работает офлайн.

**Стек:** React + TypeScript + Vite, Tailwind CSS, Dexie (IndexedDB) для хранения, vite-plugin-pwa, Vitest для тестов. Без сервера и без авторизации: все данные хранятся на устройстве, есть экспорт/импорт в JSON-файл.

---

## 1. Библиотека блюд (пополняю только я)

Разделы (категории):

- **Основное блюдо** (мясо, птица или рыба). Флаг «самостоятельное блюдо» — для плова, лазаньи, макарон по-флотски и т.п.: не требует гарнира.
- **Гарнир**
- **Салат**
- **Завтрак**
- **Перекус**
- **Обед** (супы и другие блюда специально для полноценного обеда)
- **Заготовка в морозилку** (см. п.6)

Поля блюда: название, категория, список ингредиентов (только названия продуктов, без количеств), заметка/рецепт (свободный текст), для основных — тип белка (мясо / птица / рыба / другое), флаг «самостоятельное», дата добавления, архив (скрыть, не удаляя).

При добавлении приложение само подсказывает раздел (см. п.2), я подтверждаю одним нажатием или меняю.

## 2. Автосортировка (без ИИ, локальные правила)

- Словарь ключевых слов по названию и ингредиентам, например:
  - суп/борщ/щи/солянка/уха/бульон/крем-суп → Обед;
  - салат → Салат;
  - каша/омлет/сырники/яичница/блины/оладьи/гранола/тост → Завтрак;
  - гречка/рис/пюре/булгур/киноа/картофель/овощи на гриле → Гарнир;
  - плов/лазанья/макароны по-флотски/рагу/запеканка → Основное + «самостоятельное»;
  - мясо/свинина/говядина/курица/индейка/рыба/лосось/фарш → Основное;
  - заморозка/заготовка/замороженн → Заготовка.
- Если я исправила предложенный раздел — приложение запоминает поправку и в следующий раз учитывает её (пользовательские правила важнее встроенных).
- Если правило не сработало — показать выбор раздела без подсказки.

## 3. Неделя меню

- День начала недели (= день после закупки) выбирается в настройках.
- Будни: завтрак, перекус в обед, ужин.
- Выходные (Сб, Вс): завтрак, полноценный обед, ужин (без перекуса).
- Ужин = основное + гарнир + салат. Если основное «самостоятельное» — гарнира нет, салат остаётся.
- Полноценный обед в выходные = либо блюдо из раздела «Обед» (суп и т.п.), либо основное + гарнир (можно + салат). Обеды не должны повторять ни одно блюдо из ужинов этой недели (ни основное, ни гарнир).
- Сборка: кнопка «Собрать неделю автоматически», затем ручная правка любого слота (выбор из списка нужного раздела с поиском, кнопка «Заменить на другое случайное»).
- Неделя имеет статусы: Черновик → Утверждена (формируется список покупок) → Завершена (архив).

## 4. Правила повторов

- Внутри недели одно и то же блюдо не должно встречаться дважды ни в одном разделе. При ручном выборе повтора — заметное предупреждение (жёлтая плашка у слота + общий счётчик предупреждений), но выбор разрешён.
- Окно 2 недели: блюдо, которое реально было приготовлено на прошлой неделе, не ставится на текущую. Автосборка соблюдает это строго; при ручном выборе — предупреждение «было на прошлой неделе».
- Если блюд в разделе не хватает, чтобы собрать без повторов, — автосборка берёт давно не использовавшиеся блюда, помечает слот предупреждением и пишет «В разделе Х мало блюд, добавьте ещё».
- В настройках для каждого раздела можно ослабить правило (например, разрешить повтор гарниров), по умолчанию всё строго.

## 5. Пропуски и перенос

- В утверждённой неделе любой слот (или отдельное блюдо в слоте) можно отметить «Пропущено» с причиной: «съели остатки», «ели вне дома», «другое» + комментарий.
- Пропущенное блюдо попадает в очередь «Перенос на следующую неделю». При сборке следующей недели перенесённые блюда ставятся первыми (в подходящий раздел/слот), остальное добирается автоматически.
- Пропущенное блюдо НЕ считается приготовленным: на него не действует правило 2 недель.
- Для перенесённого блюда — вопрос «Продукты ещё есть?»: если да, его ингредиенты не попадают в новый список покупок.
- Блюдо из очереди переноса можно отменить вручную.

## 6. Морозилка (отдельный раздел)

- Идеи заготовок (категория «Заготовка»): тип — ягоды/фрукты для компотов, заготовки для супов, заготовки для основных блюд, зелень, другое; источник — покупная заморозка / заморозить свежее с рынка; ингредиенты; заметка.
- «Сейчас в морозилке»: запись с названием, датой заморозки, количеством (свободный текст: «3 пакета»), кнопками «Использовала часть» / «Закончилось». Подсветка заготовок старше N месяцев (N в настройках, по умолчанию 6).
- Заготовку можно добавить в план недели как задачу «Заморозить на этой неделе» — её ингредиенты идут в список покупок; после отметки «Сделано» запись появляется в «Сейчас в морозилке».

## 7. Список покупок

- Формируется из утверждённой недели: все ингредиенты всех блюд и задач-заготовок, без дублей; у каждого продукта видно, для каких блюд он нужен (×2, ×3).
- Группировка по месту покупки (по умолчанию: Рынок, Супермаркет, Другое; список мест редактируется). Место запоминается для каждого продукта в справочнике продуктов; новый продукт по умолчанию — «Другое», меняется одним нажатием.
- «Постоянные запасы» (соль, масло, специи и т.п.) — редактируемый список, по умолчанию исключаются из покупок.
- Галочки «куплено», «уже есть дома»; ручное добавление продукта; кнопка «Поделиться списком» (текст через Web Share API / копирование).

## 8. История и данные

- Все недели сохраняются; экран истории со списком недель и просмотром любой из них, кнопка «Повторить как черновик».
- Экспорт всех данных в JSON-файл и импорт из него (с подтверждением перезаписи).
- Настройки: день начала недели, места покупок, постоянные запасы, строгость повторов по разделам, срок хранения заморозки.

## 9. Навигация (нижнее меню)

Неделя · Блюда · Покупки · Морозилка · Ещё (история, настройки, экспорт).

## Уточнения, принятые при реализации

- **Прошлая неделя** (п.4) — последняя утверждённая или завершённая неделя, начавшаяся не раньше чем за 13 дней до текущей. Черновики и пропущенные блюда не считаются приготовленными.
- **Автосборка**: сначала ужины, затем обеды выходных (поэтому обеды не повторяют блюда ужинов), затем завтраки и перекусы. Обед выходного по умолчанию — блюдо из раздела «Обед»; если свежих нет — основное + гарнир.
- **Нехватка блюд**: если свежих блюд нет, берётся блюдо, реже всего встречающееся в этой неделе, а среди них — дольше всего не готовившееся (никогда не готовившиеся — первыми).
- **«Мало блюд»** показывается, когда в строгом разделе блюд, не готовившихся на прошлой неделе, меньше, чем позиций этого раздела в неделе.
- **Ослабленное правило** для раздела: автосборка по-прежнему старается не повторять, но повторы и «было на прошлой неделе» в этом разделе не считаются предупреждениями.
- **Утверждённая неделя** не редактируется; для правки её можно вернуть в черновик.
- **Пропуски** отмечаются только в утверждённой неделе: одно блюдо, несколько или весь приём пищи. Неделю с пропусками нельзя вернуть в черновик, пока отметки не сняты.
- **Перенос**: блюда из очереди при сборке ставятся в самые ранние подходящие позиции недели (основное — на ужин, при нехватке ужинов — на обед выходного; гарнир — только к основному, которому нужен гарнир). Очередь принимает неделя, начинающаяся позже недели пропуска.
- Если перенесённое блюдо в черновике заменить, удалить черновик или пересобрать его, блюдо возвращается в очередь. В черновик его можно поставить и вручную — из блока «Из очереди переноса» в списке выбора.
- **Отмена переноса** блюда, уже стоящего в черновике, оставляет его там как обычный выбор.
- **Список покупок** строится из блюд утверждённой недели при каждом открытии, поэтому всегда совпадает с меню. В базе хранятся только отметки «куплено» / «уже есть дома» и продукты, добавленные вручную. По умолчанию открывается самая поздняя утверждённая неделя; если утверждённых несколько, между ними можно переключаться.
- Пропущенные блюда из списка не убираются: к моменту пропуска продукты обычно уже куплены.
- **Перенесённые блюда**: если на вопрос «Продукты ещё есть?» ответить «Да», их ингредиенты не попадают в список, кроме тех, что нужны другим блюдам недели. Без ответа или при «Нет» продукты покупаются. Ответ можно изменить прямо в списке покупок.
- **Постоянные запасы**, нужные блюдам недели, показываются отдельным свёрнутым блоком. Оттуда их можно одним нажатием добавить в список на эту неделю.
- **Места покупки**: можно добавлять, переименовывать, менять порядок (он задаёт порядок групп в списке) и удалять. «Другое» удалить нельзя, и оно всегда последнее. Продукты удалённого места переходят в «Другое».
- **«Поделиться списком»** отправляет только то, что ещё не куплено и чего нет дома, сгруппировав по местам, без «×N», чтобы число не читалось как количество. Если Web Share недоступен, список копируется в буфер обмена.
- **Морозилка** — две вкладки: «В морозилке» и «Идеи». Записи «Сейчас в морозилке» идут от самых старых к новым. Лежащие N месяцев и дольше (N из настроек) подсвечиваются, а сверху показывается их число. Записи можно добавлять вручную и править (название, дата, количество).
- **«Использовала часть»** спрашивает, сколько осталось, и меняет только количество. **«Закончилось»** не удаляет запись: она уходит в свёрнутый блок «Закончилось недавно», откуда её можно вернуть.
- **«Заморозить на этой неделе»** — задачи в любой незавершённой неделе, черновой или утверждённой. Добавляются из блока недели или кнопкой «В план» у идеи; если открытых недель несколько, приложение спрашивает, в какую. Одна идея — не больше одного раза в неделю.
- **«Сделано»** спрашивает дату заморозки (по умолчанию сегодня) и количество, затем создаёт запись в морозилке с названием идеи. Отметку можно снять, тогда эта запись удаляется. Удалить из плана можно только невыполненную задачу.
- Удаление черновика недели удаляет его задачи-заготовки, но не то, что уже заморожено.
- **История недель** — все недели, от новых к старым, с числом блюд и пропусков. Черновик и утверждённая неделя открываются на вкладке «Неделя», завершённая — в истории, только для просмотра.
- **«Повторить как черновик»** ставит блюда на те же дни недели (понедельник → понедельник), даже если день начала недели в настройках изменился. Отметки «Пропущено» и связи с переносом не копируются. Блюда из архива или удалённые остаются пустыми позициями. Заготовки недели копируются как невыполненные. Черновик может быть только один, как и на вкладке «Неделя»; дату начала можно выбрать.
- **Экспорт** сохраняет все таблицы в один JSON-файл `menu-planner-ГГГГ-ММ-ДД.json` с версией схемы данных. На телефоне файл отдаётся через «Поделиться» (можно сохранить в «Файлы»), иначе скачивается.
- **Импорт**: перед заменой показывается, что в файле (дата, число блюд, недель, заготовок в морозилке, продуктов), и нужно подтвердить. Файлы чужих приложений, повреждённые файлы и файлы более новой версии приложения отклоняются с понятной ошибкой. Замена идёт одной транзакцией: если что-то не загрузилось, текущие данные не меняются.
- **Настройки** сохраняются сразу. Строгость повторов задаётся для разделов, которые бывают в неделе (без «Заготовок»). Срок хранения заморозки — от 1 до 24 месяцев. Места покупок и постоянные запасы редактируются тем же блоком, что и в «Покупках». День начала недели действует для новых недель.
